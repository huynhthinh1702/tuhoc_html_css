Học thẻ code

Em đang học thẻ <em></em> và thẻ <strong></strong> 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>

Lí thuyết:

Thẻ code dùng khi có 1 đoạn code ta cho vòa thì trình duyệt sẽ hiển thì đây là code

Còn thẻ pre sẽ giữ nguyên định dạng của người viết, kết hợp với tag code thì nó sẽ giữ nguyên định dạng code mà không bị viết luôn một hàng dài.
